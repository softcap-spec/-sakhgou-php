2Откуда данные

Новая таблица дневных счётчиков — простая и достаточная:

listing_stats (listing_id, event, day, cnt, PRIMARY KEY(listing_id, event, day))
  • event = view — инкремент при каждом открытии страницы объявления;
  • event = phone — при нажатии «Позвонить» (раскрытие телефона);
  • event = chat — при первом сообщении в чат по объявлению;
  • event = favorite — при добавлении в избранное.

Брони, отзывы и промо уже лежат в своих таблицах — берём напрямую. История просмотров начнёт копиться с момента внедрения; эффект продвижения будет виден по новым данным.

3Где показываем

A Кнопка «Статистика» у объявления

В «Мои объявления» у каждой карточки + на странице статистики мини-KPI: просмотры, контакты, заявки.

Рекомендую

B Страница статистики /stats/{id}

KPI-карточки, график просмотров/контактов за 7/30/90 дней, период продвижения подсвечен на графике, таблица «до / во время / после».

График — лёгкий SVG на чистом JS, без библиотек.

C Сводная по всем объявлениям

Вкладка «Статистика» в кабинете: таблица всех объявлений продавца — просмотры, контакты, заявки, метка «продвигается», эффект промо.

4Функционал страницы статистики

  • KPI-блок: просмотры (всего / за 30 дней / в день), телефон, чаты, заявки, подтверждённые брони, конверсия, выручка от броней;
  • График просмотров и контактов за период (7/30/90 дней) с переключателем; если объявление продвигалось — период промо подсвечен;
  • Сравнение: «до промо / во время / после» — просмотры в день в каждом периоде;
  • Окупаемость: потрачено на продвижение → сколько заявок и выручки пришло за период промо;
  • Лента событий (опционально): заявки, отзывы, даты промо.

5План по этапам

1
ДанныеТаблица listing_stats + инкременты: просмотры (вместо голого счётчика), телефон, чат, избранное. ~1 час.
2

4

5
Сводная вкладкаСравнение всех объявлений продавца, включая продвигаемые. ~1 час.

6Что решить

  • Показывать окупаемость (потрачено на промо → выручка) или только просмотры/контакты?
  • График: свой SVG или использовать данные Яндекс.Метрики (она уже подключена)?
  • Начинать со всего сразу или по этапам 1→2→3→4→5?
