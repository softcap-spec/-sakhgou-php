# сахгоу.рф — PHP-версия

Маркетплейс туруслуг, рыбалки и жилья для Сахалина и Курил.

## Стек
- Чистый PHP 8.2 (без фреймворка)
- MySQL 5.7
- Tailwind CSS (CDN)
- Шрифт Manrope

## Установка
1. Скопировать `config.php.template` → `config.php`, заполнить доступы к БД
2. Импортировать структуру БД из `database/schema.sql`
3. Настроить роутинг (`.htaccess` для Apache, `try_files` для Nginx)
4. `chmod 777 uploads/`

## Структура
```
public_html/
  index.php          — роутер
  config.php         — конфиг (НЕ коммитить!)
  .htaccess          — правила роутинга
  uploads/           — загруженные фото
  assets/            — статика (лого, фавикон)
  includes/          — общие компоненты
  pages/             — страницы сайта
    admin/           — админ-панель
```
